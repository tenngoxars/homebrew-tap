# Tenngoxars Tap

## How do I install these formulae?

`brew install tenngoxars/tap/<formula>`

Or `brew tap tenngoxars/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tenngoxars/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
